# Shop photos and videos: phone se website tak

1. Phone pe github.com kholo (ya Pages CMS: pagescms.org, GitHub se login).
2. Repo `madhuban-motors` > branch `gh-pages` > folder `assets/gallery/inbox/`.
3. Service ke folder mein daalo, taaki tag sahi lage:
   `seat-covers`, `interior`, `mats`, `android-screen`, `sound-system`, `dashcam`, `lights`, `sun-film`, `ppf`, `ceramic-coating`
   (folder na ho to "Add file > Upload files" mein naam ke aage `seat-covers/` likh do).
4. File ka naam = title. Example: `creta-black-red-seat-covers.jpg` -> "Creta black red seat covers".
5. Commit dabao. 1 se 2 minute mein GitHub Action apne aap:
   - photo seedhi karta hai, thoda bright/clear/sharp karta hai, 1600px WebP banata hai
   - video ko 20 second, bina awaaz, halka MP4 + poster banata hai
   - "Fitted at our shop" gallery mein sabse upar jod deta hai
   - inbox khaali kar deta hai

Tips: iPhone pe Settings > Camera > Formats > Most Compatible (JPG), video 10 se 20 second, vertical. Number plate dikh rahi ho to pehle blur kar do.
